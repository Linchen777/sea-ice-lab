# 海冰盐度实验室

一个二维交互式平衡/概念模型，用盐度解释海冰形成的两种路径，并把**盐析**与**极地上层海水盐度剖面**放在同一个画面里。

在线地址：**https://linchen777.github.io/sea-ice-lab/**

## 打开

- 在线：直接打开上面的 GitHub Pages 地址；
- 离线：双击 `dist/index.html`；
- 本地开发：`node build.mjs` 后打开 `dist/index.html`。

## 两个视图

### 1. 形成过程

- 二维水体剖面：大气、上层海水、下层海水、混合层、对流、冰盖；
- 盐度滑块 0–35 psu；
- 初始水温、冷却进度、播放/暂停；
- 三个预设：低盐度、临界盐度、高盐度；
- 右侧 T–S 区域图：\(T_f(S)\) 与 \(T_{\rho max}(S)\)，临界盐度约 24.7；
- 右侧密度—温度曲线：最大密度点、冰点、当前状态、冷却方向；
- 状态读数：冰点、最大密度温度、上下密度差、混合层深度、冰厚倾向。

### 2. 盐析与观测

- 海冰剖面：卤水泡、排盐通道、下层海水；
- 冰龄滑块 0–5 年：冰盐度约 7 → 3 psu，卤水泡减少；
- 盐量收支：留在冰内 / 排入海水；
- 观测补充：0°、20°S、40°S、60°S 盐度—深度剖面；
- 60°S 过程叠加：结冰期（表层变咸）与融化期（表层变淡）；
- 说明观测剖面是盐析、融冰淡水、降水和混合共同作用的结果，不能单向归因于盐析。

## 关键物理

- 近似冰点：
  \[
  T_f(S) \approx -0.0575S + 1.710523\times10^{-3}S^{3/2} - 2.154996\times10^{-4}S^2
  \]
- 最大密度温度：
  \[
  T_{\rho max}(S) \approx 3.98 - 0.215S
  \]
- 两者在 \(S\approx24.695\)、\(T\approx-1.33^\circ C\) 相交；
- \(S<24.7\)：\(T_{\rho max}>T_f\)，冷却越过最大密度点后表层变轻，稳定薄层，结薄冰；
- \(S>24.7\)：\(T_{\rho max}<T_f\)，冷却一直增密，对流混合，混合层整体接近冰点，冰层倾向更厚；
- 盐析：冰盐度通常 3–7 psu，远低于海水 34–35 psu；大部分盐被排入上层海水；冰龄越大，卤水泡越少、冰盐度越低。

## 模型边界

- 二维半定量概念模型，不是海冰预报；
- 密度曲线是教学用近似，绝对密度值不重要，重点是最大密度点与冰点的相对位置；
- 混合层深度、冰厚采用示意算法，不追求真实米数；
- 观测剖面按教学图形态近似，不冒充实测数据；
- 真实海冰还受热通量、雪盖、风、海洋热通量、冰脊、卤水体积等影响。
